# 語言學習

多語言學習 App（純前端、離線可用的 PWA）。首頁 `index.html` 是語言入口，各語言在 `modules/<語言>/`。
本文件主要說明英文模組（`modules/en/`）。

## 英文模組怎麼用

底部 5 個分頁：

| 分頁 | 內容 |
| --- | --- |
| **今日** | 一顆按鈕開始「今日學習」；連續天數、今日進度、詞彙進度。學過 4 個字以上會出現「小考」。 |
| **單字** | 單字庫（清單／卡片，可搜尋、依主題與星等篩選）、翻卡複習（自評）、拆解猜意思、同根字辨析。 |
| **練習** | 文法 Part 5、閱讀 6・7、組句、詞族。 |
| **複習本** | 收藏・錯題、錯句本。 |
| **更多** | 設定與資料（學習重心、每日新內容、打字題、自動發音、聲音與語速、雲端同步、備份）、題庫匯入。 |

牌組（共約 2,830 張）：

- **外商職場片語** 234 條（13 類：通用、創新與變革、追蹤與調整進度、開始與結束、會議與討論、Email 與訊息、協作與分工、決策與優先順序、問題與風險、目標與績效、談判與客戶、簡報與數據、職涯與人資）
- **日常會話** 150 條（10 類：寒暄、意見、請求、約時間、飲食、購物、健康、情緒、交通、居家）
- **多益字彙** 986 張、**字首字根** 1,460 張

## 學習設計（為什麼這樣做）

| 做法 | 依據 |
| --- | --- |
| 每張卡都要**作答**，不是翻面自評；答對後仍會持續排入複習 | 回想練習（testing effect）：Roediger & Karpicke 2006；Karpicke & Roediger 2008 |
| 題型隨熟練度升級：選意思 → 例句挖空選字 → 例句挖空**打字** | 辨識比主動回想容易，掌握應以主動回想為準：Laufer & Goldstein 2004 |
| 新內容**先猜再學**，同一輪隔幾題再考兩次；答錯必給正解並在本輪重考 | pretesting（Potts & Shanks 2014）；節內拉開間隔（Cepeda et al. 2008） |
| 間隔重複：答對 1→3→7→14→30→60→120 天，答錯降級、隔天再考 | spacing effect；延長版 Leitner（未採用需要大量參數校正的 FSRS） |
| 每輪量小（最多 20 張複習＋5 個新內容），每日新內容預設 10 個 | 每個新項目約帶來 7～10 次複習（Anki／Refold 經驗值）；小而可持續 |
| 學的單位是**片語＋完整例句＋中譯＋用法提醒** | 詞塊需要刻意練習才學得會：Boers & Lindstromberg 2012 |
| 新字依學習重心輪流抽，同一輪避開同類別的片語 | 近義項目一起學會互相干擾：Tinkham 1993/1997、Waring 1997、Nation 2000 |
| 連續天數每 7 天容許 1 個休息日 | 連續紀錄中斷會降低後續參與，可修復則緩解：Silverman & Barasch 2023 |
| 首頁只有一個主要動作 | 降低開始的門檻（產品慣例；無直接實證） |

「今天」以裝置當地日期計算（舊版用 UTC，台灣早上 8 點才換日）。

## 檔案結構

```
index.html                 語言入口（登入、模組列表）
modules.js                 語言模組登錄表
sw.js                      Service Worker（network-first；新增資料檔要加進 PRECACHE_URLS 並調整 CACHE_NAME）
modules/en/index.html      英文模組（程式＋內建多益題庫與單字）
modules/en/data/phrases.js 片語牌組（外商職場 work-*、日常會話 daily-*）
modules/en/data/*.js       組句、問句、詞族、同義詞資料
modules/shared/            句子引擎、詞族引擎
modules/es、modules/fr      西文、法文模組
```

### 新增片語

編輯 `modules/en/data/phrases.js`，在該牌組最後加一筆並接續流水號：

```js
{"id":"work-235","theme":"work","cat":"會議與討論","word":"circle up","pos":"phr./v.","meaning":"…",
 "example":"Let's **circle up** after lunch.","exampleZh":"…","collocations":[],"tip":"…","stars":4}
```

- 例句用 `**…**` 標出片語在句中的確切字串（可含時態變化），供粗體顯示與挖空出題。
- `id` 發佈後不可更動或重用——學習紀錄以 `id` 為鍵。
- `word` 不要與既有單字重複（選項與打字判定以 `word` 區分）。

## 學習紀錄與同步

- 紀錄存在每台裝置瀏覽器的 localStorage；用 Google 登入後會透過 Google Drive（appDataFolder）在裝置間自動同步。
- 未登入時可到「更多 → 設定與資料」下載備份檔，到另一台「合併匯入」（合併是冪等的，來回同步不會亂）。
- 學習偏好（學習重心、每日新內容等）隨紀錄一起備份與同步。
